# JavaTraining

## 課題① Java基礎

### 課題内容

* 社員データを5件作成
* Stream APIを使用し30歳以上の社員を抽出
* 抽出した社員名一覧を出力
* 部署ごとの人数を集計

### 使用技術

* Java
* List
* Stream API

### ファイル構成

```text
src
├ Employee.java
└ Main.java
```

### 実行方法

Main.java を実行してください。

### 実行結果例

30歳以上の社員一覧

佐藤次郎

田中一郎

高橋美咲

部署ごとの人数

営業部：2人

開発部：2人

人事部：1人

### 学習内容

* クラスの作成
* Listによるデータ管理
* Stream APIによるデータ抽出
* groupingByを使用した集計処理
